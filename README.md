# CoreT — AI-Powered Banking Workflow Assistance

**Developed by:** Akshat Soni  
**Institution:** Poornima Institute of Engineering and Technology, Jaipur  
**Project Status:** Functional, deployed prototype

## Overview

CoreT is an AI-powered digital banking workflow assistance platform designed to simplify traditional banking-related processes through guided digital workflows, document processing and intelligent assistance.

## QR Code System

The QR system provides a direct QR-based entry point to the CoreT User Panel.

It includes:
- High-resolution PNG
- Scalable SVG
- Print-ready PDF
- QR generation script
- Validation utilities

## Key Capabilities

- Guided banking workflows
- OCR-assisted document processing
- Digital banking form assistance
- QR-based access
- AI-assisted banking guidance
- Admin-side workflow verification
